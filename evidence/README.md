# Evidence Folder

This folder stores real screenshots captured from:

- the running local React application
- the live API response

Expected files:

- `app-desktop-home.png`
- `app-fullscreen-home.png`
- `app-fullscreen-workflow.png`
- `app-fullscreen-visa-query.png`
- `app-details-view.png`
- `app-mobile-view.png`
- `api-response-base.png`
- `api-response-page2.png`
- `api-response-visa.png`

Supporting live-response snapshots:

- `api-base-live.json`
- `api-page2-live.json`
- `api-base-live.html`
- `api-page2-live.html`
- `api-visa-live.json`
- `api-visa-live.html`

Note:
The in-app browser blocked direct rendering of the raw API endpoint, so the JSON was captured live from the endpoint during implementation and then rendered locally into HTML for readable screenshots. The underlying data in those screenshots is still from the real live API.
