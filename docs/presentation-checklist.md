# Presentation checklist

What to have open and what to click during the live demo.

## Before the demo

- [ ] GitHub repo open in one tab.
- [ ] `README.md` rendered in another tab.
- [ ] Postman with the three saved requests loaded.
- [ ] Browser tab with the live API URL.
- [ ] Terminal in `assignment1/` with `pnpm dev` running.
- [ ] DevTools Network tab open so the class can see the fetches.

## During the demo

- [ ] Run the three Postman requests once each.
- [ ] Open the app and walk through the hero + API summary panel.
- [ ] Switch to the Page 2 tab. Show the new GET URL and the new fetch in DevTools.
- [ ] Switch to the Visa sponsorship tab. Same thing.
- [ ] Click the copy button on the request line and paste it into the URL bar to prove it matches.
- [ ] Type a search. Show that no new request fires.
- [ ] Change the sort. Toggle remote-only. Confirm the counter updates.
- [ ] Click Reset filters. Counter goes back to full.
- [ ] Pick a job on the left. Click "Open the original posting" and let the new tab open.
- [ ] Mention: provider, root URL, resource path, GET, JSON, `page`, `visa_sponsorship`.
