# Postman Demo Files

Import `arbeitnow-assignment1.postman_collection.json` into Postman.

The collection includes:

- the base `GET` request used by the app
- a second request with `?page=2` for the query-parameter demo
- a third request with `?visa_sponsorship=true`, which is also implemented inside the app

Suggested screenshots to take from Postman:

1. successful base request
2. successful `page=2` request
3. successful `visa_sponsorship=true` request
4. visible JSON fields in the response body
